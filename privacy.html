Política de Privacidade — Gestor Financeiro

Última atualização: 2026.

O Gestor Financeiro é uma aplicação de gestão financeira pessoal de utilização privada e individual, não destinada à distribuição pública nem à gestão de dados de terceiros.

Dados recolhidos

  • Dados de conta criados pelo próprio utilizador (email, movimentos, contas, categorias, orçamentos, objetivos).
  • Quando o utilizador liga uma conta bancária através do Enable Banking: identificação da conta (nome, IBAN), saldos e histórico de movimentos.

Acesso apenas de consulta

A integração com o Enable Banking é utilizada exclusivamente para consulta de saldos e extração de movimentos (Account Information Services). Esta aplicação não inicia pagamentos, transferências, nem qualquer outra operação sobre as contas bancárias ligadas.

Armazenamento e acesso

Os dados são armazenados numa base de dados privada (Supabase), protegida por autenticação e controlo de acesso ao nível de cada registo. Apenas o próprio utilizador (e, quando aplicável, membros que este convide explicitamente para a sua carteira) tem acesso aos seus dados. Os dados não são vendidos, partilhados ou utilizados para fins publicitários.

Chaves e credenciais

As credenciais de acesso à API do Enable Banking (incluindo a chave privada de assinatura) são geridas exclusivamente do lado do servidor e nunca são expostas à aplicação cliente (telemóvel ou browser).
